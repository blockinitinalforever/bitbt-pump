# 2026-09-11 原版 UI 对齐复查

依据用户提供的 ZIP 和同目录 README，重新解压后核对，未修改原包。

## 修改前已确认不一致（基线记录，不是当前状态）

原版含 28 个 panel，现有页面不是原版 DOM 的完整照搬。
原版三个 style 区块字符数为 21331、8542、104914；当前为 38115、13829、124896，三个区块均不同。

原版有 success、income-center、developer-tools、invite-center、alert-center、protection、language-center、action-center。
当前主页面缺少这些同名 panel，另有旧 perpetual、alerts、growth、revenue-center、vault-store、developer-center。
因此问题不仅是样式，还包括账户入口、页面结构与数据适配器对旧 panel 的绑定。

## 修复原则

- 以原版 DOM、层级、CSS、字体、图标和响应式布局为基线，不继续给旧页面堆样式。
- 原版假价格、假持仓、收益和成功结果不能重新上线；真实 API、钱包、回执、鉴权及异常状态保留。
- 逐项迁移旧面板的数据绑定到原版对应容器，不能仅恢复按钮却留下不可达页面。
- 真实后端未支持的全仓、Robinhood 永续等能力保持清晰不可用说明，不伪装可交易。
- 保留之前明确要求：无 GW、单一钱包入口、底部联系方式、全路径 favicon、移动端购买入口、详细错误弹窗。
- 桌面和移动端同尺寸比对原包与候选版，交互/鉴权/交易回归完成后单独提交 PR；未经命令不部署。
