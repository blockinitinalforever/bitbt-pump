对应 API `fix/perpetual-lifecycle-20260913`；需一起复审，未经部署命令不上线。

- 使用 API operationsState 区分按需待命、准备中、可交易和真实异常，不再用前端计时器猜测所有情况。
- dataStale 的市场快照明确提示；交易仍请求最新 prepare，不直接用旧展示数据签名。
- 账户/网络和 calldata 绑定；开平仓 deadline 必须等于 expiresAt，价格上下界有效。

- 发送中断没有哈希时明确保留 unknown，需要钱包核查；拒签 4001 清除提交标记。
- 已付费对手池注资复用同一授权/核心交易执行流程；不会重复支付平台服务费。
- 注资广播哈希按申请 ID 保存；完成接口失败后的重试只补回写，不重复注资。
- 唤醒重试窗口扩到约 120 秒，以容纳 Keeper 60 秒有限退避；不是无限轮询。
